# Noobic-Stratocracy-HOI4
NSTNO mod made by @eunewsaccount

To setup hoi4 mod while i cannot upload it to steam workshop


1. go to your hoi4 mod folder /.local/share/Paradox Interactive/Hearts of Iron IV/mod (this is for linux) will be different on windows
2. make a folder called NSTNO then download the github REPO
3. upload all contents from the github REPO into the NSTNO folder you just made
4. Setup your NSTNO.mod file (it will be in your hoi4 mod folder NOT NSTNO folder)

NSTNO.mod will look like this 

picture={
	"thumbnail.png"
}
version="0.1"
tags={
	"Alternative History"
	"Gameplay"
}
name="Noobic Stratocracy The New Order"
replace_path="history/countries"
replace_path="history/states"
replace_path="history/units"
replace_path="history/general"
replace_path="map/strategicregions"
replace_path="map/supplyareas"
replace_path="map"
replace_path="common/ai_strategy"
replace_path="common/ai_strategy_plans"
replace_path="common/decisions"
replace_path="common/decisions/categories"
supported_version="1.19.4.1"
path="/home/archiea/.local/share/Paradox Interactive/Hearts of Iron IV/mod/NSTNO"
remote_file_id="3829676912"

once you put that into NSTNO.mod just boot up HOI4 and you should be able to find it
